3. Explique em uma frase, sem código, a diferença entre map e filter.

A diferença é que o map transforma os elementos de uma lista, enquanto o filter seleciona apenas os elementos que atendem a uma condição.

10. Qual a diferença entre import Botao from "./Botao.js" e import { Botao } from "./Botao.js"?

import Botao from "./Botao.js" importa o export padrão, enquanto import { Botao } from "./Botao.js" importa um export nomeado.
