1. Em uma frase, sem código: o que é uma Promise?
    É o resultado de uma futura ação, ele pode tanto funcionar quanto falhar

2. Quais os três estados possíveis de uma Promise?
    pending: em andamento;
    fulfilled: concluída com sucesso;
    rejected: concluída com erro.

buscarProduto(3)

.catch((erro) => console.log(erro));
        async function mostrarProduto() {
        try {
            const produto = await buscarProduto(3);
            console.log(produto);
            } catch (erro) {
        console.log(erro);
            }
        }
    mostrarProduto();

6. Escreva uma função assíncrona chamada buscarProduto que recebe um id, espera 1 segundo e devolve o
objeto { id, nome: "Produto "+ id } (use Promise e setTimeout, como no exemplo da seção 2).
    function buscarProduto(id) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve({
        id,
        nome: "Produto " + id
      });
    }, 1000);
  });
}
