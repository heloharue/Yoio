# Backlog do Projeto
| Prioridade | História de usuário | Critérios de aceite |
|------------|---------------------|----------------------|
| Essencial | Como criança, quero abrir o aplicativo e ver a tela inicial de forma clara para que o uso seja intuitivo. | 1. Tela de boas-vindas com o nome da criança. 2. Botão grande de "jogar". 3. Fontes amplas e contraste adequado. |
| Essencial | Como criança, quero escolher entre diferentes mini-games para treinar habilidades variadas sem ficar entediado. | 1. Menu com pelo menos 3 opções de jogos. 2. Cada jogo com cor diferente. |
| Essencial | Como criança, quero jogar um mini-game de associação para praticar vocabulário. | 1. Exibe 4 figuras e 4 palavras. 2. Feedback visual (verde/vermelho). 3. Mostra quantos acertos teve. |
| Essencial | Como criança, quero receber feedback imediato ao acertar ou errar para entender meu desempenho na hora. | 1. Som e animação para acerto. 2. Som suave para erro. |
| Essencial | Como criança, quero avançar para uma próxima fase após completar um jogo para sentir que estou progredindo. | 1. Botão "Próximo" ao final. 2. Fases com níveis mais difíceis. 3. Barra de progresso. |
| Importante | Como criança, quero acumular pontos a cada acerto para ver meu desempenho e me sentir recompensado. | 1. Contador de pontuação visível. 2. Exibe total ao final da fase. |
| Importante | Como criança, quero pausar o jogo a qualquer momento para descansar sem perder o progresso. | 1. Botão de pausa em todas as telas. 2. Opções "Continuar" e "Sair". 3. Progresso é salvo ao sair. |
| Importante | Como criança, quero ter ajustes de dificuldade para jogar no meu ritmo e não me frustrar deixando o jogo. | 1. Opção "Fácil / Médio / Difícil". 2. Padrão é Fácil. |
| Desejável | Como criança, quero personalizar meu avatar para me identificar mais no jogo. | 1. Opções de cor de pele, cabelo, camiseta. 2. Avatar aparece na tela inicial. 3. Alterações salvas automaticamente. |
| Desejável | Como criança, quero ganhar medalhas por sequências de acertos para ter metas extras. | 1. Medalhas como "10 acertos seguidos". 2. Álbum de medalhas no menu. |
| Futuro | Como responsável, quero ver um relatório do progresso para acompanhar o desenvolvimento do aprendizado da criança. | 1. Área restrita com senha. 2. Gráfico de desempenho por jogo. |
| Futuro | Como criança, quero jogar em dupla com um amigo para aprender junto e desenvolver o companheirismo. | 1. Opção "Dois jogadores" no menu. 2. Cada um joga em seu dispositivo. 3. Pontuação combinada ou competitiva. |
